## About

A single-page portfolio site in plain HTML, CSS and vanilla JavaScript.
No frameworks, no dependencies, no build step.

## Features

- Responsive layout for mobile and desktop
- Scroll reveal animations that respect reduced motion settings
- Online or Offline status with a live uptime counter
- Expandable Nuitka details under Decompilation
- Tool tags that link to official project pages
- Tap to copy BTC address
- Fonts fade in on load to avoid a flash of unstyled text

## Stack

- HTML, CSS and JavaScript
- Cormorant Garamond, Inter and JetBrains Mono from Google Fonts
